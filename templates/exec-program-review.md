# Executive Program Review (30 min)

1. **Decisions needed** (first, not last)
2. **Portfolio health:** one row per program (status, trend, top risk)
3. **Escalations:** what's blocked, by whom, the ask
4. **Financials:** spend vs. plan, headcount asks, vendor renewals
5. **Next two weeks:** milestones and risks

Send a pre-read 24 hours ahead. Record decisions and owners in the same doc.
