# AI Tooling Rollout & Adoption

1. **Pilot:** 2-3 teams, a baseline measured first (velocity, cycle time, quality)
2. **Champions:** one per team; weekly office hours; shared prompt and pattern library
3. **Training:** role-based, hands-on, recorded
4. **Policy:** approved tools, data handling, code review expectations, IP and licensing
5. **Model choice:** hosted vs. self-hosted, decided on cost, data governance and capability
6. **Measure:** adoption rate, velocity, change failure rate, developer sentiment
7. **Scale:** expand by team readiness, not by date. Retire what doesn't move the numbers.

**Exit criteria for each phase:** metric thresholds met, policy signed off, support in place.
