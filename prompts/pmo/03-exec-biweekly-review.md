# Executive Biweekly Review (one page)

**Use when:** presenting program status to a CTO/VP group.
**Style:** narrative first, metrics second (the Amazon-style written review).

## Prompt
~~~
You are a Senior Staff TPM writing the biweekly executive review. I will paste my portfolio data and notes below.

Write a ONE-PAGE document in full sentences with these sections, in this order:
1. Headline: one sentence on net portfolio position.
2. Decisions needed: top 3, each with the decision, owner, deadline, and what happens if we do not decide.
3. Portfolio table: program, overall RAG, trend arrow, one-line status.
4. Red/Amber deep dive: what happened, root cause, recovery plan, date it returns to Green/Amber.
5. Wins: 2-3, each with a metric.
6. Financials: spend vs budget, savings realized vs committed.
7. Next two weeks: milestones due.
Rules: lead with the ask; no unexplained acronyms; every number must come from my data, and if a number is missing, write [NEED DATA] instead of inventing it; cut anything an executive cannot act on. After the page, list the 3 questions the CTO is most likely to ask and a crisp answer for each, using only my data.

MY DATA AND NOTES:
[PASTE HERE]
~~~
