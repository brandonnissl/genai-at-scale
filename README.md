# TPM Playbook

Practical, open templates for Technical Program Managers running platform migrations, PMOs and AI adoption programs. Battle-tested on a 450+ microservice Kubernetes migration, a 10+ program portfolio, and an AI-assisted development rollout across 400+ developers. Free to copy and adapt.

## Templates
| Template | Use it to |
|---|---|
| [Migration go/no-go](templates/migration-go-no-go.md) | Decide whether a service or team is ready to cut over |
| [Cutover plan](templates/cutover-plan.md) | Run a cutover with clear owners, checkpoints and rollback |
| [PMO & portfolio governance](templates/pmo-governance.md) | Stand up quarterly planning, intake and exec reporting |
| [AI rollout & adoption](templates/ai-rollout-adoption.md) | Take AI tooling from pilot to org-wide use |
| [GenAI use-case intake](templates/use-case-intake.md) | Score and prioritize AI ideas |
| [Executive program review](templates/exec-program-review.md) | Run a two-week business review that drives decisions |
