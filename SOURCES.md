# Sources

Frameworks these prompts draw on. Links were checked and resolved when this repo was last updated. Specific thresholds and weights in the prompts are the author's recommended defaults, not figures from these sources.

## Migration
- Google SRE Book: [Launch checklist](https://sre.google/sre-book/launch-checklist/), [Reliable product launches](https://sre.google/sre-book/reliable-product-launches/), [Production readiness (SRE engagement model)](https://sre.google/sre-book/evolving-sre-engagement-model/), [Postmortem culture](https://sre.google/sre-book/postmortem-culture/)
- AWS Prescriptive Guidance: [Migration strategies (the 7 Rs)](https://docs.aws.amazon.com/prescriptive-guidance/latest/large-migration-guide/migration-strategies.html)
- Azure Cloud Adoption Framework: [Migrate](https://learn.microsoft.com/en-us/azure/cloud-adoption-framework/migrate/)
- [Kubernetes best practices](https://kubernetes.io/docs/setup/best-practices/)
- [Atlassian postmortem handbook](https://www.atlassian.com/incident-management/handbook/postmortems) · [PagerDuty postmortems](https://postmortems.pagerduty.com/)
- DORA: [Four key metrics](https://dora.dev/guides/dora-metrics-four-keys/)
